Severity Classification

Every finding is categorized before you see it, so you fix critical vulnerabilities first.

SeverityWhat lands hereWhat CodeRefine does
CRITICAL Exploitable from outsideInjection, unsafe deserialization, auth bypass, eval on user input. Blocks the summary, shows the patched line, names the attack path.
HIGH Leaks or crashes under loadCommitted secrets, missing validation, swallowed exceptions, unbounded reads. Patched line plus the config or guard you'd need alongside it.
MEDIUM Costs you laterN+1 queries, duplicated logic, functions doing four jobs, dead branches. Suggests the refactor, keeps behaviour identical.
